Methodology: users are randomly split 50/50 into control (served Popularity-baseline recommendations) and treatment (served Hybrid recommendations). For every recommended impression we simulate a click via a logistic function of the item's true relevance to that user's hidden taste profile (unknown to the model, known only to the simulator) plus random noise — i.e. clicks are not hand-picked to favor the treatment, they're generated from the same relevance model for both arms. Significance is computed with a two-proportion z-test, cross-checked against a chi-square test of independence (chi2 = 23.276, p = 0.00000).

Resume-ready summary

Developed a hybrid (collaborative + content-based) recommendation system and validated impact via a simulated A/B test against a popularity baseline, demonstrating a +18.9% lift in CTR (statistically significant, p = 0.0000). Evaluated ranking quality offline with Precision/Recall/NDCG@10 across four model variants (popularity, collaborative filtering via SVD, content-based, and hybrid).
